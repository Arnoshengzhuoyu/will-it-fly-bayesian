Will It Fly? Predicting Echo-MS detectability from chemical structure with Bayesian models

Course project proposal · Bayesian machine learning · November 2026

In one sentence: I’d like to use a compound’s structure to predict how likely we are to detect it in positive-ion mode on the Echo-MS, as a calibrated probability, with uncertainty that grows for unusual molecules. In chemistry terms this is a QSAR/QSPR model, built the Bayesian way.

1. Background (for readers outside chemistry)

Mass spectrometry in one paragraph. A mass spectrometer is a very precise scale for molecules, but it can only weigh molecules that carry an electric charge. So the sample is first sprayed into a fine, charged mist (“electrospray”), where some molecules pick up a charge. In positive-ion mode the instrument looks for molecules that gained one extra proton (H+). For a molecule of mass M it watches the signal at M + 1.007 (written [M+H]+). The output is a peak area: roughly, how many of those ions reached the detector.

“Will it fly?” Chemists say a compound “flies” if it gives a clear peak. Whether it does depends on its chemistry:

  • Molecules with a basic nitrogen (amines, pyridine-type rings) grab a proton easily and usually fly.
  • Molecules with an acidic group (e.g. carboxylic acids) would rather lose a proton and usually don’t. They might show up in negative-ion mode, which isn’t in this dataset.
  • Size and how “oily” vs. “water-loving” a molecule is (logP) matter too [1].

These are tendencies, not rules, which makes this a natural problem for a probabilistic model.

The Echo-MS, and why this matters. Normally each sample runs through a chromatography column first, which takes minutes. The Echo-MS (SCIEX Echo MS+) skips that step. A sound pulse shoots a nanoliter droplet out of a well in a 1536-well plate into a carrier solvent, which flows into the electrospray source. That takes under 2 seconds per sample [2]. The price is one generic set of conditions for every compound, so some compounds just don’t give a usable signal.

OpenADMET (an open-science consortium) and Octant (a biotech company) use the Echo-MS to measure how liver enzymes break down drug-like compounds, by watching how much of each compound disappears. A compound that doesn’t fly can’t be measured this way, so they pre-screen whole libraries first. A model that works from structure could flag such compounds before anyone buys or plates them, and say how much to trust each call.

This is a QSAR problem. Predicting a property of a molecule from its structure is what chemists call QSAR (quantitative structure–activity relationship). When the target is a physical or chemical property rather than a biological activity, as it is here, it is often called QSPR (structure–property relationship). QSAR studies follow a standard workflow: curate the data, compute descriptors, select features, split the data, build the model, validate it, define where it can be trusted (its applicability domain), and interpret it. The OECD’s five principles for QSAR models say much the same thing: a defined endpoint, an unambiguous algorithm, a defined applicability domain, proper validation, and a mechanistic interpretation where possible [3, 4]. My plan (Section 4) follows this workflow step by step and uses Bayesian methods inside it.

2. Data

Source. I found the “Will It Fly” data in a public Zenodo dataset released by OpenADMET and Octant (“Data release: Building the OpenADMET data engine”, record 21450795, July 2026, CC BY 4.0) [5]. The raw file is will_it_fly_in_mass_spec.tsv, and the companion blog post describes the experiment [6]. The file has 11,353 rows (one per compound) and four columns:

ColumnMeaning
ocnt_batchCompound ID
standardized_smilesStructure as a SMILES string, a text code for a molecule (e.g. CCO is ethanol)
ammonium_formate_areaPeak area with 5 mM ammonium formate added to the carrier solvent
ammonium_fluoride_areaPeak area with 1 mM ammonium fluoride added to the carrier solvent

So each compound has one value per carrier-solvent additive, with no enzyme involved. The additive changes how easily molecules get charged.

First look (my own quick analysis):

  • There is no yes/no label, only peak areas. 362 compounds (3.2%) have an area of exactly 0 with formate, and 208 (1.8%) with fluoride. Presumably that means “no peak found”.
  • Non-zero areas run from about 20 to about 750,000. On a log scale they form one smooth hump (Fig. 1A), with no natural gap between “flies” and “doesn’t”. So “flies” really means “above a chosen cutoff”.
  • The blog says ~50% of the library passed with formate and ~75% with fluoride. A cutoff of 10,000 reproduces this (52.9% and 78.6%), so I’ll use it as the default. I’m not sure it’s exactly their rule, though.
  • The two additives agree strongly (log-area correlation 0.95). Fluoride gives more signal for 98% of the compounds detected under both, 2.9× more on median.
  • Chemistry matters (Fig. 1B). With formate, 69% of compounds with a basic N and no acid fly, compared with 5% of those with an acid and no basic N.
  • The library is very diverse. 89% of compounds have a ring scaffold that no other compound shares, and the median Tanimoto similarity to a compound’s nearest neighbor is only 0.43 (on a 0–1 scale).
  • The file doesn’t name the ion. In the companion reactivity file, the target mass is always the neutral mass + 1.007, i.e. [M+H]+ (all 1,223 compounds), so I assume the same here.

Feasibility check (not Bayesian). With 5-fold CV at the 10,000 cutoff, logistic regression on 21 simple descriptors reaches AUC 0.846 (formate) / 0.825 (fluoride). A random forest on fingerprints plus descriptors reaches 0.885 / 0.864, and a cluster-based split costs less than 0.01. So structure carries real signal, but the predictions are far from certain. That’s the setting where honest uncertainty is worth having.

3. Goal and questions

Build a QSPR model that, given only the structure, outputs P(detected in positive mode on the Echo-MS) with honest uncertainty: confident for familiar chemistry, cautious for unusual molecules.

  • Q1. How well does structure predict flying, and are the probabilities calibrated? (Of compounds given 70%, do about 70% actually fly?)
  • Q2. Should I model the yes/no label, or model the peak area and derive the probability from it?
  • Q3. Which chemical features drive detection, and how sure are we about each effect?
  • Q4. Does the model’s uncertainty work as an applicability domain (does it flag the compounds the model gets wrong), and can it help decide which compounds are worth measuring?

Steps 1–4: data, descriptors, features, splits

Curation is light because the SMILES are already standardized. All 11,353 parse in RDKit, none are salts or mixtures, all contain only organic elements, and there are no exact duplicates. Two things need care. First, 13 groups of stereoisomers (27 compounds), plus one compound entered twice, look identical to a 2D fingerprint, so each group goes into the same split. Second, the endpoint itself: “detected” is a cutoff on the peak area, and the zeros are censored (Section 2). Model 2 handles both.

Descriptors. Rather than writing features from scratch, I’ll start from the descriptor code the lab already used in earlier projects: the xenosite.predict.v1.features modules of the lab’s xenosite-predict package, beginning with phase1_mol.py [12]. That gives 16 whole-molecule descriptors (atom and bond counts, TPSA, logP, molecular weight, molar refractivity, H-bond donors/acceptors, ring count). It also gives atom-level features (partial charges, lone pairs, aromaticity, electron-donating/withdrawing groups). Those relate directly to whether a molecule can pick up an H+, so I’ll summarize them per molecule, e.g. the values at the most basic nitrogen. I’ll add simple counts of basic and acidic groups, plus 2,048-bit Morgan fingerprints for the GP kernel [7].

Feature selection. After dropping constant and highly correlated descriptors (|r| > 0.9), I’ll let the prior do the selection instead of a stepwise search. With automatic relevance determination (ARD), each coefficient gets its own prior precision, and the precisions are set by maximizing the marginal likelihood (the evidence):

wj∼𝒩(0,αj−1), 𝛂^=arg max𝛂 ∫p(𝒟∣𝐰)p(𝐰∣𝛂)d𝐰

Irrelevant descriptors are pushed to αj→∞ and switched off. Bayesian-regularized QSAR models have used this idea before [8, 9]. In the GP, ARD length-scales on the descriptor kernel do the same job.

Splitting. 20% is held out as an external test set, with 5-fold CV on the rest. I’ll use both random and cluster-based splits (k-means on fingerprints). Scaffold splits don’t work well here because almost every scaffold is unique.

Step 5: model building

Model 1: Bayesian logistic regression

The label is yi=1 if the area is above 10,000:

p(yi=1∣𝐱i,𝐰) = σ(𝐰⊤𝐱i), 𝐰∼𝒩(𝟎,τ2𝐈)
  • The posterior has no closed form. I’ll use the Laplace approximation (a Gaussian at the MAP, with covariance equal to the inverse Hessian) and check it against MCMC (NUTS). The default prior is 𝒩(0,1) on standardized coefficients, with the ARD prior as the alternative.
  • Predictions integrate over the posterior. With the probit approximation [8]: p(y⋆=1∣𝐱⋆,𝒟) = ∫σ(𝐰⊤𝐱⋆) p(𝐰∣𝒟)d𝐰 ≈ σ(μ⋆1+πs⋆2/8) where μ⋆ and s⋆2 are the posterior mean and variance of 𝐰⊤𝐱⋆. Inputs the model is unsure about get pulled toward 0.5.

Model 2: censored regression on the log peak area

Cutting at 10,000 throws information away: areas of 9,000 and 30 both become “0”. Instead I can model the area itself,

zi=log10(areai)=f(𝐱i)+εi, εi∼𝒩(0,σε2),

and treat the zeros as left-censored below a detection floor c ≈ log10 20, the smallest areas in the file. This gives the Tobit likelihood:

p(𝒟∣f,σε)= ∏areai>0 𝒩(zi∣f(𝐱i),σε2) × ∏areai=0 Φ(c−f(𝐱i)σε)

For any cutoff T, the detection probability is then a posterior predictive quantity:

P(flies∣𝐱⋆,𝒟)= P(z⋆>log10T∣𝐱⋆,𝒟)= Φ(μ⋆−log10Tσε2+s⋆2)

This combines model uncertainty (s⋆2, the posterior variance of f(𝐱⋆)) with measurement noise. A bonus: the cutoff becomes a decision made after fitting, so if the lab changes its threshold, nothing needs retraining. The noise also seems to grow near the detection floor (open question 3), so I’ll try letting σε depend on the predicted level, or use a Student-t likelihood. f starts linear in the descriptors and becomes a GP in Model 3.

Model 3: Gaussian process with a molecular-similarity kernel

Here f∼𝒢𝒫(0,k) with the Tanimoto kernel on fingerprints [10], which is the fraction of substructures two molecules share. I may add an RBF kernel on the descriptors.

k(𝐱,𝐱′)=θ⋅ ⟨𝐱,𝐱′⟩ ‖𝐱‖2+‖𝐱′‖2−⟨𝐱,𝐱′⟩ (optionally+kRBF)
  • 3a uses a probit likelihood on the label, and 3b uses the censored likelihood of Model 2. Both need approximate inference (Laplace or EP) [11].
  • Kernel choice and hyperparameters (θ, length-scales, σε) are set by maximizing the approximate log marginal likelihood.
  • 11k compounds means an 11k × 11k kernel matrix and O(n3) cost, so I’ll fit on a ~3–5k subset or use inducing points.
  • With such a diverse library, I honestly don’t know whether the fingerprint kernel will beat simple descriptors.

Extension: both additives jointly. Share strength across the two additives, e.g. 𝐰fluoride=𝐰formate+𝛅 with 𝛅∼𝒩(𝟎,λ2𝐈) and separate intercepts. The posterior on λ says whether fluoride just shifts everything up, or helps some chemistry more than others.

Using existing ionization models. If I find published models that predict ionization efficiency or protonation (e.g. pKa predictors), I won’t compete with them. I’ll build on them instead: their prediction m0(𝐱) becomes the prior mean, f∼𝒢𝒫(m0,k). The GP then only has to learn what is specific to the Echo-MS. The existing model on its own is also a baseline to beat. Because this prior comes from outside this dataset, it avoids the double-dipping worry in open question 4.

Step 6: validation

  • Internal and external validation, as in standard QSAR practice [4]: 5-fold CV on the training set, and the held-out 20% test set, used only once at the end.
  • Y-randomization: shuffle the labels (or areas), refit, and check that performance drops to chance. This catches chance correlations and data leakage.
  • Metrics: AUC, balanced accuracy and MCC (the usual classification-QSAR metrics), plus log loss, Brier score and reliability diagrams for the probabilities. For Models 2 and 3b, also RMSE on log area and the coverage of 90% predictive intervals.
  • Posterior predictive checks: does the model reproduce the fraction of zeros, and the detection rate in each chemistry group of Fig. 1B?
  • Baselines and success: the baselines are the overall rate, plain logistic regression and a random forest. Success means matching them on AUC and beating them on log loss and calibration, especially for test compounds unlike the training set.

Step 7: applicability domain

Classic QSAR defines the applicability domain separately, for example by similarity to the nearest training compound, or by the leverage h(𝐱)=𝐱⊤(𝐗⊤𝐗)−1𝐱 (the “Williams plot”) [4]. A Bayesian model has one built in. For Bayesian linear regression, the predictive variance of a new compound is

Var[z⋆∣𝐱⋆,𝒟]= σε2(1+𝐱⋆⊤(𝐗⊤𝐗+σε2τ2𝐈)−1𝐱⋆)

With a flat prior (τ→∞) this is exactly σε2(1+h(𝐱⋆)). So the classic leverage rule is a special case of Bayesian predictive uncertainty, and the GP extends it to fingerprint similarity. I’ll check whether high predictive uncertainty really flags the compounds the model gets wrong (error-vs-uncertainty curves), compared with the classic similarity and leverage rules.

Step 8: interpretation and use

Interpretation (OECD principle 5): each descriptor’s posterior gives an effect with a credible interval, e.g. “a carboxylic acid lowers the odds of flying by a factor of X (95% credible interval a–b)”. I can then check that the signs agree with chemistry. Use (stretch goal, Q4): simulate pre-screening. Start from a few hundred labeled compounds, repeatedly “measure” the most uncertain ones (by predictive entropy or expected information gain), and compare the learning curve with random picking.

5. Open questions (feedback welcome)

  1. Label or area? Classifying at a cutoff is simpler. The censored model uses more information but needs a noise model on the log scale. I’ll compare held-out log loss, but is one of them clearly more appropriate?
  2. What do the zeros mean? If they mean “below detection”, censoring is right. But a zero could also mean the compound wasn’t really in the well (it didn’t dissolve, it decomposed, or the dispense failed), which would call for a zero-inflated mixture. Zeros are 13% among acids vs. 1% among basic compounds, so at least some of them come from chemistry.
  3. The noise is probably not constant. There are no replicates, but the formate/fluoride pairs help. The spread of their log ratio is about 0.2 log10 units when both areas are above ~3,000, but 0.4–0.5 below 1,000. The 13 stereoisomer groups (rough replicates) show the same pattern. Is it reasonable to build an informative prior for a level-dependent σε from these numbers, given that they come from the same data?
  4. Priors from chemistry. I already know (and have now seen) that amines help and acids hurt. Is encoding that in the priors double-dipping? My plan is weakly informative or ARD priors for the main results, and chemistry-informed priors only as a sensitivity check. Priors taken from an external model (see “Using existing ionization models”) would avoid the problem.
  5. GP scale. Should I use an exact GP on a subset, or a sparse approximation on all 11k compounds?
  6. Cutoff and saturation. The lab’s real pass rule may involve signal-to-noise or a background that changes with mass. Also, no formate area is above ~420,000, and the fluoride gain shrinks at the top (median 1.8× for the strongest signals vs. 2.9× overall). That would fit detector saturation. Should the top end be right-censored too?
